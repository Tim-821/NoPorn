# 🛡️ 朋友监督者 3 分钟极简操作 SOP

> **给监督朋友的话**：谢谢你帮哥们一把！你平时**完全不需要主动盯着他**，也不用懂任何技术，总共只需要第一次花 3 分钟配置，以后偶尔收到手机弹窗花 2 秒点一下“同意/拒绝”就行。

---

## 第一步：在朋友手机上开启审批通知（2 选 1，1 分钟搞定）

### 情况 A：朋友用 iPhone（最推荐，极简稳定）
1. 打开 App Store，搜索下载免费软件 **Bark**（图标是个小喇叭/铃铛）；
2. 打开 Bark，允许推送通知；
3. 首页会看到一串以 `https://api.day.app/一串随机字符/` 开头的链接，点击复制发给本人（用于填进 Cloudflare 推送后台，填完立刻生效）。

### 情况 B：朋友用安卓手机（连 App 都不用装，直接微信收通知）
1. 微信搜索并关注 **PushPlus 推送加**（或 **Server酱**）公众号；
2. 点击菜单获取自己的 `Token`（或 `SendKey`），复制发给本人填进后台即可。

---

## 第二步：平时怎么审批软件？（2 秒钟完事）

1. 当对方要装冷门正经软件（例如学校网课软件“学堂在线”）而 AI 没自动放行时，你的手机会收到一条弹窗/微信推送：**`Mac安装申请: XXX`**；
2. 点开推送里的链接，页面上会清清楚楚显示：
   - **软件名称**
   - **开发者签名 / 是否通过苹果官方公证**
   - **AI 拦截原因**
   - **对方写的备注**
3. 判断很简单：
   - 确认是正经学习/办公/游戏软件 → 点绿色按钮 **【✅ 同意安装】**（仅限这 1 个文件、5 分钟内有效，绝对不可能被拿去偷装 VPN）；
   - 如果看着像 VPN / 梯子 / 代理 / 陌生浏览器 / 奇怪程序 → 直接点 **【❌ 拒绝】**！
4. **全程你不需要知道、也不需要发送任何电脑密码。**

---

## 第三步：最终封口时，朋友保管的 3 样钥匙（只做一次）

等对方在手机和电脑上**稳定试运行 3 天确认一切日常顺畅**后，做一次最终交接：

1. **接管 Cloudflare 账号**：登录对方提供的 Cloudflare 账号（`your-cloudflare-email@example.com`），把密码改成只有你知道的密码（顺便确认 API Token 可删掉，防止本地再改审核规则）。
2. **远程盲敲修改 Mac 管理员 `guard` 密码**：
   - 电脑装好免费的 **RustDesk**；
   - 让对方切到 Mac 的 `guard` 管理员账号，发给你 RustDesk 连接码；
   - 你远程连上后，在 **系统设置 → 用户与群组 → `guard` → 更改密码** 里直接用你自己的键盘输入新密码（屏幕上只显示 `••••••`，对方看不到），记在你的备忘录里即可。
3. **保管手机签名密钥备份 `guard.jks`**：
   - 接收对方发来的 `guard.jks` 和 `guard-password.txt` 存进你的网盘/备忘录，确认保存好后，让对方从自己电脑彻底删除本地副本。

---

## 应急说明（一年最多用 1 次）
- 如果对方真的遇到极其特殊的情况（比如系统大版本升级或必须用管理员权限修电脑），微信联系你用 **RustDesk** 远程连进来 30 秒，你直接盲敲一次 `guard` 密码点确定后断开即可——**永远不要把密码明文发在聊天框里**。
